# AI interaction log

This directory is the source-controlled record of AI assistance used to build SRE Copilot.

- `2026-10-21-build-log.md` records the assessment prompt, reviewed proposal, implementation
  decisions, and validation outcomes from the initial build session.
- Add exported transcripts from the coding client here when preparing the public assessment
  submission. Keep user prompts, assistant responses, and tool calls; remove credentials,
  machine-specific secrets, and private chain-of-thought.

The implementation intentionally exposes concise reasoning summaries in the product UI rather than
raw chain-of-thought.
